# sameshark2.github.io

個人的な練習・遊び用のリポジトリです。
中身は **3つのフォルダ** に分かれていて、それぞれ別のゲーム／サイトです。

| なに | 開くリンク | フォルダ |
|---|---|---|
| 🐰 しほんぬタッピング！（詩歩ちゃん専用ゲーム） | https://sameshark2.github.io/shiho/ | [`shiho/`](shiho/) |
| ✨ 新時代（スマホのセンサーで絵を描く） | https://sameshark2.github.io/shinjidai/ | [`shinjidai/`](shinjidai/) |
| 📘 Progate 練習サイト | https://sameshark2.github.io/progate/ | [`progate/`](progate/) |

トップページ https://sameshark2.github.io/ には、上の3つへのリンクが並んでいます。

## フォルダの中身

- `shiho/` … しほんぬタッピング！
  - `index.html` ゲーム本体
  - `voice/` 「あたっ！」の声のファイル
  - `icon-*.png`, `manifest.json` ホーム画面に追加したときのアイコンと名前
- `shinjidai/` … 新時代
  - `index.html` アプリ本体（1ファイルだけ）
- `progate/` … Progate の練習ページ
  - `index.html`, `stylesheet.css`, `top.png`
- `index.html`（いちばん上）… 3つへのリンクを並べたトップページ
